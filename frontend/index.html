PROBLEM & MOTIVATION

Clouds routinely block optical Earth observation

Cloud cover is a major source of data loss in optical Earth observation. Reconstructed pixels are estimates, not measurements, so this tool keeps a confidence map alongside every result.

Input formatsPNG · JPG · TIFF
Cloud maskThreshold heuristic
ReconstructionLaMa + 3 classical
ProcessingBackground queue
\1Crop-stress windows, flood peaks and disaster response timelines do not wait for clear skies. An estimate of what is under the cloud can help decide where to look next, but it should never replace a clear acquisition for analysis that needs measured values.\2

Agriculture monitoring

Crop-health indices need continuous time series. A single missed acquisition during a pest outbreak or irrigation decision window can mean acting a week too late.

Disaster management

Floods and cyclones are themselves cloud-generating events — the moments responders need imagery most are exactly when optical sensors are most occluded.

Acquisition planning

A reconstructed preview can help triage which scenes need re-acquisition, though it does not remove the need for ground truth.

PROCESSING PIPELINE

From upload to reconstructed output

Six stages. Cloud detection is a simple threshold heuristic, so check the confidence map before relying on a result.

01

Image upload

A PNG, JPG or TIFF (up to 100 MB) is uploaded into a project and stored in cloud storage.

INPUT: PNG · JPG · TIFF
02

Cloud detection

Bright, low-saturation pixels are flagged as likely cloud. Bright snow, sand or buildings can be mistaken for cloud.

METHOD: HSV threshold
03

Mask cleanup

Morphological opening and closing remove speckle and close small gaps in the detected regions.

METHOD: morphology
04

Cloud mask

The result is a binary occlusion mask: the only region the reconstruction step is allowed to change.

OUTPUT: binary mask
05

Reconstruction

Masked pixels are filled by the model you choose: a pretrained LaMa network, or one of three classical OpenCV inpainting variants.

MODELS: LaMa · OpenCV ×3
06

Result and confidence map

A reconstructed PNG is returned with a confidence map: pixels far from any cloud score high, cloud interiors score lower.

OUTPUT: PNG + confidence map

BACKGROUND: GENERATIVE APPROACHES

Generator, discriminator, and the diffusion alternative

Adversarial reconstruction pits two networks against each other; diffusion reconstruction instead denoises a masked region step by step. This section explains the ideas only: this deployment runs a pretrained LaMa network and classical inpainting, not a GAN or a diffusion model.

Diffusion: denoising instead of guessing in one shot

Rather than generating the missing region in a single forward pass, a diffusion model starts from noise inside the masked area and removes it gradually, at each step conditioning on the surrounding unmasked pixels. The result tends to be more stable on large, irregular cloud masks where GAN-based inpainting can produce visible seams.
